# 🏢 현진인테리어 프리미엄 브랜드 홈페이지

현진인테리어(Hyunjin Interior)의 브랜드 전문성을 선보이고, 잠재 고객에게 쉽고 빠른 원스톱 공간 인테리어 매칭 서비스를 제공하는 프리미엄 브랜드 단일 페이지 웹 애플리케이션(SPA)입니다.

본 웹사이트는 세련된 타이포그래피, 마이크로 애니메이션, 다크/라이트 테마 제어 및 풍부한 반응형 계산 시스템을 탑재하여 최고의 사용자 경험(UX)과 브랜딩 인상을 주도록 개발되었습니다.

---

## 🎨 주요 프리미엄 기능 명세

1. **디자인 시스템 및 테마 스위치 (Aesthetic Systems)**
   - **프리미엄 컬러 조합**: 딥 차콜과 프리미엄 골드/브론즈 컬러를 기반으로 신뢰감과 고급스러움을 연출합니다.
   - **실시간 테마 토글**: 사용자 브라우저 환경 및 기호에 맞춰 부드러운 트랜지션과 함께 작동하는 **실시간 다크 모드 / 라이트 모드** 전환을 완벽 지원합니다.
   - **Glassmorphism 헤더**: 스크롤 상태 감지에 따라 배경 블러 및 불투명도가 동적으로 달라져 프리미엄 웹 특성을 강조합니다.

2. **실시간 프리미엄 견적 계산기 (Premium Receipt Calculator)**
   - **유형별 자동 산정**: 카페/F&B, 아파트/주거, 일반상가/오피스, 도배/장판 마감 등 시공 종류별 평당 기본 단가 산정.
   - **자재/마감 등급제 반영**: 실속형(Economy), 고급형(Standard), 프리미엄형(Premium) 자재 및 비스포크 가구 구성 배율 적용.
   - **실시간 반응형 양방향 바인딩**: 슬라이더 및 입력 상자로 면적(평수)을 조절하면 즉각적으로 영수증 명세와 예상 총공사비 범위가 만원 단위로 산출됩니다.
   - **상담 신청 연동**: "위 견적 결과로 상담 신청하기" 클릭 시, 입력한 견적 내용이 하단 **상담신청 폼으로 자동 매핑**되며 부드러운 스크롤 이동이 실행됩니다.

3. **포트폴리오 카테고리 필터링 (Portfolio Filter)**
   - 전체보기, 카페/F&B, 아파트 주거, 마트/상업유통 등 카테고리를 클릭하면 부드러운 스케일/페이드 트랜지션 애니메이션과 함께 관련 실적 카드만 선별되어 노출됩니다.

4. **모바일 반응형 슬라이드 내비게이션 (Mobile-Responsive)**
   - 모바일 기기(768px 이하)에서 작동하는 부드러운 슬라이딩 햄버거 메뉴 및 스크롤 이벤트 연동으로 완벽한 하이브리드 네비게이션 편의를 선사합니다.

5. **개인정보 수집 동의 및 커스텀 모달 알림**
   - 브라우저 기본의 식상한 `alert()` 대신, 성공을 강조하는 폭죽 애니메이션을 탑재한 커스텀 디자인 모달창을 적용했습니다.

## 🛠️ 사용 기술 스택

- **마크업**: HTML5 (시맨틱 태그 준수, SEO 최적화 메타 데이터 세팅 완료)
- **스타일링**: Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Media Queries)
- **로직**: Vanilla JavaScript (ES6+, Intersection Observer API)
- **아이콘**: Inline SVG Vector Icons (별도의 무거운 프레임워크나 외부 폰트 라이브러리 없이 초고속 로딩 지원)
- **폰트**: Google Fonts (Outfit, Noto Sans KR)

## 💻 로컬 실행 방법

본 프로젝트는 순수 웹 프론트엔드로 빌드 과정이 필요 없이 어떤 브라우저에서나 즉시 실행이 가능합니다.

1. **간편 실행 (더블 클릭)**
   - `index.html` 파일을 크롬, 엣지, 사파리 등 임의의 브라우저에서 더블 클릭하여 실행합니다.

2. **로컬 개발 서버 실행 (추천)**
   - VS Code의 `Live Server` 확장을 사용하거나 터미널에서 다음 명령을 실행하여 로컬 포트로 호스팅합니다:
     ```bash
     # python이 설치되어 있는 경우
     python -m http.server 8000
     
     # Node.js가 설치되어 있는 경우
     npx serve
     ```
   - 브라우저 주소창에 `http://localhost:8000` 또는 `http://localhost:3000`을 입력하여 접속합니다.

본 웹사이트 프로젝트는 아래 원격 저장소 주소와 직접 1:1로 매핑되도록 내부 Git 설정이 완료되거나 가이드되어 있습니다:
`https://github.com/hjhomeinterior/design.io.git`

### 로컬 최초 설정 및 원격 연동 (자동 수행 완료 상태)

```bash
# 1. 로컬 저장소 초기화 및 기본 브랜치 지정
git init -b main

# 2. 원격 저장소 추가 (origin)
git remote add origin https://github.com/hjhomeinterior/design.io.git

# 3. 소스 파일 전체 스테이징 및 커밋
git add .
git commit -m "feat: 현진인테리어 프리미엄 홈페이지 및 견적 계산기 1차 릴리즈"

# 4. 원격 저장소로 첫 푸시 실행
# (참고: 사용자 컴퓨터의 GitHub 권한 및 자격 증명이 되어 있어야 작동합니다)
git push -u origin main
```
